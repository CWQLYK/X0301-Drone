# X0301四轴无人机代码项目 
## 项目概述
本项目是基于 STM32F103C8T6 主控芯片的四轴无人机完整代码实现，适配四轴飞行器硬件平台。代码集成了 MPU6050 姿态解算、串级 PID 控制、2.4G 无线通信、电机驱动等核心功能，支持二次开发与算法优化，适用于新手入门、电子竞赛、四轴产品开发及业余爱好者学习使用。

## 硬件适配信息
### 核心硬件参数
| 组件 | 型号/规格 | 功能说明 |
|------|-----------|----------|
| 主控芯片 | STM32F103C8T6 | 系统核心控制单元，负责算法执行与外设驱动 |
| 姿态传感器 | MPU6050（6轴陀螺仪+加速度计） | 采集飞行姿态原始数据，支持角度解算 |
| 无线通信模块 | SI24R1（2.4G） | 实现遥控器与飞行器的无线数据传输（理论通信距离50米） |
| 电机驱动 | MOS管 A03400（A09T） | 驱动720电机，支持0.5A额定负载、1.5A堵转电流 |
| 电源 | 3.7V 600mAh 锂电池 | 为飞行器提供动力，整机重量51g（含电池） |
| 遥控器 | STM32F103C8T6 + SI24R1 | 含油门/方向摇杆、校准/微调按键、蜂鸣器，预留OLED接口 |

### 扩展功能支持
- 预留气压计接口（需自行添加硬件），支持高度控制扩展
- 支持接入光流模块，实现悬停功能
- 外设接口：I2C + USART1 + USART3 + 2个预留IO口

## 代码结构说明
### 核心文件目录
```
├── ALL_DEFINE.h          // 全局宏定义（状态标志、硬件引脚、常量参数）
├── main.c                // 程序入口（系统初始化、主循环调度）
├── MPU6050.c             // MPU6050传感器驱动（数据采集、校准、滤波）
├── imu.c                 // 姿态解算（四元数算法，转换Pitch/Roll/Yaw角）
├── pid.c                 // PID控制（串级PID实现，角度环+角速度环）
├── control.c             // 飞行控制（电机混控、PWM驱动、解锁逻辑）
├── remote.c              // 遥控器数据解析（2.4G通信协议处理、通道映射）
├── ANO_DT.c              // 匿名上位机通信（数据上传、参数调试）
├── filter.c              // 滤波算法（卡尔曼滤波、低通滤波、中值滤波）
├── myMath.c              // 数学工具库（三角函数、矩阵运算、数据限幅）
└── scheduler.c           // 任务调度（多周期任务管理）
```

### 核心功能模块
1. **系统初始化模块**（`main.c`/`ALL_Init.c`）
   - 硬件初始化：I2C、UART、PWM、MPU6050、NRF24L01
   - 软件初始化：PID参数配置、任务调度器初始化、看门狗配置
2. **姿态解算模块**（`imu.c`/`MPU6050.c`）
   - 原始数据采集：MPU6050加速度计+陀螺仪数据读取
   - 滤波处理：卡尔曼滤波（抑制噪声）、一阶低通滤波（平滑数据）
   - 四元数解算：将传感器数据转换为地理坐标系下的Pitch（俯仰）、Roll（横滚）、Yaw（偏航）角
3. **PID控制模块**（`pid.c`）
   - 串级PID结构：外环（角度环）+ 内环（角速度环）
   - 控制对象：3个串级PID分别对应横滚角、俯仰角、偏航角
   - 参数配置：支持通过代码或上位机调整KP（比例）、KI（积分）、KD（微分）参数
4. **遥控器通信模块**（`remote.c`/`NRF24L01.c`）
   - 2.4G数据解析：解析遥控器油门、方向、模式等通道数据
   - 解锁逻辑：支持组合键解锁（油门最低+偏航右打），防止误启动
   - 失联保护：遥控器信号丢失时自动关闭电机，保障安全
5. **电机驱动模块**（`control.c`）
   - PWM生成：通过TIM2/TIM3生成4路PWM信号，控制电机转速
   - 电机混控：根据PID输出与飞行原理，分配4个电机的动力输出
   - 安全保护：油门低于阈值时关闭电机，紧急状态下强制停转
6. **任务调度模块**（`scheduler.c`）
   - 多周期任务：2ms（核心控制）、4ms（通信处理）、6ms（姿态解算）、10ms（遥控解析）等
   - 任务优先级：核心控制任务（PID、电机驱动）优先级最高，保障实时性

## 快速上手指南
### 1. 代码编译与下载
1. 打开 Keil5 工程，选择 `Project -> Rebuild all target files` 编译代码
2. 连接调试器与飞行器，选择 `Flash -> Download` 将程序下载到主控芯片
3. 断开调试器，安装锂电池，开启飞行器与遥控器电源

### 2. 解锁与飞行操作
| 操作步骤 | 具体操作 | 备注 |
|----------|----------|------|
| 设备启动 | 开启遥控器电源，再开启飞行器电源 | 遥控器默认左油门（右油门需修改代码） |
| 解锁准备 | 遥控器油门推至最低（<1150），偏航摇杆右打（>1800） | 保持2秒，LED常亮表示解锁成功 |
| 基本飞行 | 推油门控制升降，方向摇杆控制前后左右，偏航摇杆控制旋转 | 新手建议在空旷场地试飞，低速飞行 |
| 上锁操作 | 油门推至最低，偏航摇杆右打保持2秒，或关闭遥控器电源 | LED闪烁表示上锁成功 |

## 关键参数配置
### PID参数调整（`pid_param_Init.c`）
默认参数适用于此项目硬件，若飞行不稳定可按以下规则调整：
```c
// 内环角速度PID（响应速度）
pidRateX.kp = 1.7f;  // 横滚角速度比例系数（增大→响应变快，过大会抖动）
pidRateY.kp = 1.7f;  // 俯仰角速度比例系数
pidRateZ.kp = 3.0f;  // 偏航角速度比例系数（偏航响应稍慢，可适当增大）
pidRateX.kd = 0.08f; // 横滚角速度微分系数（增大→抑制抖动，过大会滞后）

// 外环角度PID（稳态精度）
pidPitch.kp = 7.0f;  // 俯仰角比例系数（增大→角度跟踪更准，过大会超调）
pidRoll.kp = 7.0f;   // 横滚角比例系数
pidYaw.kp = 7.0f;    // 偏航角比例系数
```
- 调试顺序：先调横滚角→俯仰角→偏航角，先调内环（角速度）→外环（角度）
- 优化目标：飞行稳定无抖动，响应迅速，无明显超调

### 滤波参数调整（`filter.c`）
- 卡尔曼滤波：调整Q（过程噪声）、R（测量噪声），Q增大→响应变快，R增大→滤波更强
- 低通滤波：调整滤波系数（如0.15f），系数越大→数据越平滑，但响应越慢

### 代码修改建议
- 新增功能时，建议在`Duty_xxms()`中添加对应周期的任务，避免影响核心控制的实时性
- 修改PID参数后，建议通过上位机监控数据，逐步微调，避免大幅修改导致飞行失控
- 扩展硬件时，需在`ALL_DEFINE.h`中添加对应的引脚定义，确保硬件兼容性

## 常见问题排查
1. **程序无法下载**
   - 检查调试器连接是否正确，电源是否正常
   - 确认Keil中芯片型号选择为STM32F103C8T6
   - 检查看门狗是否启用，若启用需在下载前关闭
2. **MPU6050初始化失败**
   - 检查I2C引脚接线是否正确（SDA/SCL）
   - 确认MPU6050芯片是否接触良好，可重新焊接
   - 检查`MPU6050_Init()`中的WHO_AM_I寄存器读取是否为0x68
3. **飞行不稳定（抖动/漂移）**
   - 机械原因：螺旋桨安装是否牢固，电机是否水平，机架是否变形
   - 软件原因：PID参数过大（减小KP/KD），滤波系数过小（增大低通滤波系数），传感器校准不充分
4. **遥控器无响应**
   - 检查NRF24L01模块接线是否正确，电源是否稳定
   - 确认飞行器与遥控器的通信频道一致（代码中`NRF24L01_Init()`配置）
   - 检查遥控器电池电量是否充足，油门是否在解锁范围内

## 注意事项
1. 飞行前务必检查电池电量，避免飞行中断电
2. 调试时建议使用调试架固定飞行器，防止电机启动后翻倒
3. 首次飞行选择空旷、无障碍物的场地，远离人群与建筑物
4. 修改代码后建议先进行地面测试（电机空载运行、姿态数据监控），再进行试飞
5. 严禁在室内或人员密集区域进行高速飞行，确保飞行安全
